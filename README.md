# FLOWSTATE
1.Залейте все файлы в репозитории GitHub (веб-интерфейс, позволяющий создавать файлы с путями).

2.Действия вкладки: сборка запускается при каждом нажатии в main; повторно — запустить рабочий процесс.

3.Готовый JAR: запуск сборки → Артефакты → flowstate-xyz (ZIP) → распаковать → в .minecraft/mods.

4.Рабочий процесс сам представляет собой актуальный API пряжи/загрузчика/Fabric и возникает понятная ошибка, если версия minecraft_version не существует в Meta Fabric.

5.При падении тестов скачайте протоколы испытаний.

Хоткей
F9 (по умолчанию) переключает HUD. Меняется в устройстве игры (Управление → FLOWSTATE) или полем hudToggleKeyCode в конфиге (0 = выключено). Изменение showHud хоткеемсохраняется в конфиге при выходе из клиента (не в игровом цикле).

Порядок тик-обработчиков (внутреннее, но важный)
END_CLIENT_TICK: (1) TicketTracker.onTickEnd → (2) chunkWindow.onTickEnd → (3) планировщик/горячая клавиша.Не менять порядок — длительность тика должна фиксироваться до записей в окне чанков
